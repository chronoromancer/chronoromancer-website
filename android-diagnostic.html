This test build helps us investigate Android lag and unusually large save files.

简体中文说明

这是专门用于排查卡顿和存档变大的安卓诊断版，请按下面的方法安装和测试：

1．直接更新，保留存档

打开这个 APK，在现有游戏上直接安装更新。不要先卸载游戏，也不要清除游戏数据。

如果提示无法更新或安装失败，请先告诉我们，不要通过卸载来解决。

2．选择开启诊断

启动时请选择 “YES / 开启诊断”。每次重新启动都会询问，测试时都请选择 YES。

开启后，会自动向开发者发送本游戏的存档副本、进度与设置、性能数据及崩溃信息，用于排查问题，不会删除你的原始存档。

进入游戏前会先上传原始存档。存档较多时需要等待，请保持联网并等待完成，建议使用 Wi-Fi，避免消耗较多流量。

3．读取最容易卡顿的存档

请读取你平时出现问题的存档，尤其是存档明显变大的 New Game+（新游戏＋）存档，不需要重新开档。

4．按平时的方式玩，让卡顿出现

建议正常游玩约 15～20 分钟，并尽量包含这些操作：

  • 进行几场普通战斗或地牢战斗，让战后的自动保存正常完成。
  • 手动保存一次，可以存到空存档位，保留原来的存档。
  • 正常移动、切换地点，以及打开平时容易卡顿的菜单；如果 Extras 页面也会卡，请打开一次。

遇到卡顿时，先等它自行恢复，恢复后继续玩一会儿，方便记录卡顿前后的情况。如果发生闪退，请告诉我们当时正在做什么。

资料会自动发送，你不需要找存档文件，也不需要手动发送诊断报告。 测试后请回复一下大致测试时间，以及最明显的卡顿发生在哪一步，方便我们对应记录。

想停止诊断时，退出游戏，重新启动并选择 “NO / 不开启诊断” 即可。之后收到普通新版，也可以继续直接安装更新。

English Instructions

This is a special Android build to help us investigate lag and unusually large save files. Please follow these steps:

1. Update without removing your saves

Open the APK and install it as an update over your existing game. Do not uninstall the game or clear its data.

If Android says it cannot update or install, please tell us first. Don’t uninstall the game to get around the error.

2. Choose YES for diagnostics

When the game starts, choose YES to enable diagnostics. It asks again every time you restart, so please choose YES during testing.

This automatically sends the developer copies of your game saves, progress/settings, performance measurements, and crash information. It does not delete your original saves.

Before entering the game, it will upload your original saves. This may take some time if you have many saves. Please stay connected and wait for it to finish. Wi-Fi is recommended to avoid using a lot of mobile data.

3. Load the save that has the problem

Load the save you normally experience lag with—especially your New Game+ save if it has become unusually large. You don’t need to start a new game.

4. Play normally and let the lag happen

Please play for around 15–20 minutes, ideally including:

  • Several ordinary or dungeon battles, allowing the automatic save afterward to finish.
  • One manual save. You can use an empty slot to keep your previous save.
  • Normal movement, travel between locations, and opening menus that usually lag. If Extras also freezes, please open it once.

When the game pauses, give it time to recover, then continue playing for a while so we can capture what happens before and after the lag. If it crashes, please tell us what you were doing.

Everything is sent automatically. You don’t need to find save files or manually send a diagnostic report. After testing, please tell us approximately when you tested and which actions caused the most noticeable lag, so we can match them to the records.

To stop diagnostics, quit the game, restart it, and choose NO. When we send the next normal version, you can install that as an update too.
