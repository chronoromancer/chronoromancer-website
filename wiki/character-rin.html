Meet Rin

Rin belongs to the separately installed optional world Wildheart: Wild Woods. This guide covers the current personal scenes, three Heart-to-Hearts, a river date and daily gifts. It gives access and progression steps without retelling the scenes.

Where to find Rin

Install the official optional package, enable it in Mod Manager and restart after changing its enabled state. Fulfil the Wildheart access requirement supplied with that package. The base game alone does not include this world.

From Deep Woods, use Enter Wild Woods to reach the Gateway, then take the world map to Lantern Market. Rin is present all day, every day once the world is accessible. Individual events and invitations still have the time windows below.

When the next step is missing

  • If the world is missing, check installation, enabled state, restart and the package’s access requirement separately.
  • Raise ordinary affection to the required stage, complete the named previous event and finish the specified Heart-to-Heart. Extra gifts cannot replace a missing shared event.
  • Return inside the start window. Being present all day does not make every conversation or date available all day.
  • A used one-time date or stat reward disappears. The repeatable final conversation has its own daily allowance.
  • The river date begins from the character’s home menu; travelling to the riverside alone does not start that invitation.

认识Rin

Rin属于需要另行安装的可选世界「Wildheart：野林」。本页整理此版个人事件、三段交心、河上约会与日常赠礼，说明进入条件和推进步骤，保留场景内容供你亲自体验。

去哪里找Rin

先安装官方可选包，在主菜单的「模组管理器」中启用，改变启用状态后重启游戏，再完成该包提供的Wildheart访问要求。仅有游戏本体，并不会出现这个世界。

从深林的入口选择进入野林，到达「野林入口」后，用世界地图前往灯笼集市。世界可访问后，Rin每天全天在这里；具体事件和邀约仍有下表所列时段。

下一步不出现时检查什么

  • 世界入口缺失时，分别检查安装、启用状态、重启与可选包的访问要求。
  • 把普通好感提高到指定阶段，完成具名事件与交心；多送礼物不能代替共同事件。
  • 在开始时段内回来。人物全天在场，不代表每段交心或约会都全天开放。
  • 已完成的一次性约会或属性奖励会消失；最后一段可重复交心另有每日额度。
  • 河上约会从人物常驻地点的行动菜单发起；自己走到滨河步道，不会自动开始邀约。
